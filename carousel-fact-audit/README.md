# Carousel Fact Audits

This folder stores pre-design technical audits for ACME Integrity LinkedIn carousels.

The rule is simple: no final carousel image generation until the key claims have been checked against `docs/source-materials\`.

Each audit should make it clear which slide claims are verified, which need confirmation, and what must be rewritten before design.

Every audit must also include:

- Technical explanation check.
- Visual accuracy check.
- Tool image source used, if any.
- Business objective of the post.
- Final gate summary before generation.
