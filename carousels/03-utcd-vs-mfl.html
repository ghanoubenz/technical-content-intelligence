THE REALITY

MFL

METAL LOSS DETECTION

Magnetic field saturates pipe wall

Leakage at thin spots

= corrosion, gouges, thinning

UTCD

CRACK DETECTION

Ultrasonic pulses find cracks

SCC, fatigue, seam weld

= crack-like features

Different physics. Different purpose.

ACME Integrity
THE INSIGHT

MFL finds: corrosion, gouges, general thinning

MFL misses: cracks

UTCD finds: SCC, fatigue, seam weld cracks

UTCD misses: broad corrosion mapping

Running MFL and expecting it to find cracks is like using a metal detector to find glass.

ACME Integrity
WHEN TO USE WHICH

Corrosion risk → MFL

Crack risk → UTCD

Both risks → Run both

High-consequence areas and aging pipelines often need combined technology.

Tool selection starts with threat assessment, not habit.
