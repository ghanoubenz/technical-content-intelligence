IN PRACTICE

A single ILI run tells the operator what is there today.

Two runs — on the same pipeline, years apart — tell the operator what is changing. That is a fundamentally different and more valuable dataset.

One run is a snapshot. Two runs reveal the trajectory.

THE INSIGHT

The most important data point is not the current depth. It is the rate of change.

A feature at 40% growing at 2% per year is a different problem than a feature at 40% that has not grown in five years.

Static features are monitored. Growing features are managed. The difference requires two data points.
