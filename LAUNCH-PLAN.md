| Post ID | Content Piece | Used in Email | Campaign | Replies | Meeting Booked | Notes |
|---------|---------------|---------------|----------|---------|----------------|-------|

Status flow: IDEA → DRAFTED → DESIGNED → APPROVED → POSTED

## Step 3: Set Up Design Workflow (No Canva)

**Option A: Google Slides (Easiest)**
- Create a template slide deck at 1080x1350px
- Use the color scheme: dark background (#0F1923), amber accent (#F59E0B), white text
- Export slides as PNG images
- Upload to LinkedIn as document/carousel

**Option B: HTML → Screenshot (From this system)**
- Open the HTML carousel files in a browser
- Set browser window to 1080x1350
- Take screenshots of each slide
- Or use a script to batch convert

**Option C: PowerPoint**
- Same as Google Slides but offline
- Set custom slide size to 1080x1350px

---

## Step 4: Set Up Buffer (Free)

1. Go to buffer.com → sign up free
2. Connect your LinkedIn company page
3. Free plan = 3 channels, 10 scheduled posts
4. This is enough for 2-3 posts/week

**Alternative:** Post directly from LinkedIn (no tool needed)

## Step 6: Design the First 3 Carousels

### Using Google Slides:

1. Open Google Slides
2. File → Page Setup → Custom: 20.32 cm x 25.4 cm (or 1080x1350 px ratio)
3. Create 6 slides per carousel using this template:

```
Slide 1: TITLE
- Background: #0F1923
- Accent bar at top: #F59E0B
- Category label: amber, small, uppercase
- Title: white, bold, large
- Subtitle: grey (#94A3B8)

Slide 2: PROBLEM
- Label: "THE PROBLEM" in amber
- Main text: white, large
- Supporting text: light grey

Slide 3: REALITY
- Label: "THE REALITY" in amber
- Numbered points or cards
- Dark cards (#1E293B) with amber borders

Slide 4: INSIGHT
- Label: "THE INSIGHT" in amber
- Key data or framework
- Green checkmarks / red X marks

Slide 5: TECHNICAL LINK
- Label: "THE TOOL CONNECTION" in amber
- Tool cards with descriptions
- Connect problem to your specific tool

Slide 6: TAKEAWAY
- Label: "TAKEAWAY" in amber
- Summary statement
- CTA in amber border box
- Company logo bottom-left
```

4. Download → PNG images (each slide)
5. Upload to LinkedIn as a document post

# PHASE 3: GO LIVE (Week 1)

## Step 7: Post Schedule — Week 1

| Day | What | Action |
|-----|------|--------|
| **Tuesday** | Carousel: "How MFL Actually Works" | Post at 8 AM (your audience timezone). Engage 30 min in comments. |
| **Thursday** | Single Post: Industry insight (AI in inspection) | Post at 8 AM. Respond to every comment. |
| **Saturday** (optional) | Single Post: Short observation | Light post. Industry trend or question. |

### Posting Checklist (Every Post):

- [ ] Hook works in <210 characters
- [ ] No banned words
- [ ] Formatted for mobile (short lines)
- [ ] 3-5 hashtags at bottom
- [ ] Soft CTA (question or save prompt)
- [ ] Link in first COMMENT (not in post body)
- [ ] Engage in comments 30-60 min after posting
- [ ] Update Google Sheet status → POSTED
- [ ] Save post URL

---

## Step 8: First Comment Template

After every post, immediately add a first comment:

```
For more technical breakdowns on pipeline inspection
and ILI tools, visit: [your website URL]

Or follow this page for weekly insights.
```

This drives website traffic without hurting the post's algorithm reach.

# PHASE 4: WEEKLY ROUTINE (Ongoing)

## Every Week — Content Production Cycle

| Day | Task | Time |
|-----|------|------|

---

# PHASE 5: MONTHLY REVIEW (30 min/month)

## End of Each Month:

1. **Export LinkedIn analytics** → update Performance sheet
2. **Find top 3 posts** → what topic? what format? what hook?
3. **Find bottom 3 posts** → what missed?
4. **Check outreach** → which content was reused in emails? Results?
5. **Plan next month** → 8-12 topics, assign to calendar
6. **Adjust** → more of what worked, less of what didn't

# HOW TO USE CLAUDE CODE FOR THIS

## Content Generation Commands

### Generate a carousel:
```
Write a 6-slide LinkedIn carousel about [TOPIC].
Pillar: [educational / problem / product / insight]
Tool: [UTCD / MFL / EMAT / UTWM / Cleaning]
Structure: Title → Problem → Reality → Insight → Tool Link → Takeaway
Include the LinkedIn caption and HTML output.
Writing style: simple, direct, practical. Not academic. Not marketing-heavy.
```

### Generate a single post:
```
Write a LinkedIn single post about [TOPIC].
Angle: [problem / insight / educational]
Tool connection: [tool name]
Keep it under 1500 characters. Simple language. Soft CTA at end.
```

### Generate a video script:
```
Write a 60-second video script concept about [TOPIC].
Format: hook (3 sec) → explanation (45 sec) → takeaway (12 sec)
Include text overlay suggestions for each section.
```

### Generate email outreach with content:
```
Write a cold email that includes our LinkedIn carousel about [TOPIC]
as a value-add. Not salesy. Technical credibility approach.
```

### Monthly planning:
```
Based on our content pillars (educational, problem, product, insight, event),
suggest 12 post topics for [MONTH]. Mix of carousels and single posts.
Include tool connections and hooks for each.
```
